# Elsewhere

A cinematic five-chapter parallax story built as a static GitHub Pages experience with semantic HTML, responsive CSS, Anime.js 4.5, and an optional procedural ambient soundtrack.

## Live URL

https://sioteyu.github.io/elsewhere/

## Production characteristics

- No build step, database, framework, tracking, or cookies
- AVIF artwork with explicit dimensions, hero preloading, and deferred loading
- Scroll-linked Anime.js motion with reduced-motion support
- Keyboard-visible focus, semantic navigation, descriptive image text, and a skip link
- Responsive layouts for desktop, tablet, and mobile
- Graceful static fallback when the animation CDN is unavailable

## Local preview

Serve this directory through any static HTTP server. For example:

```bash
python -m http.server 4173
```
